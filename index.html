Why snapsift

Built on Apple's own frameworks. All on-device.

🔒

Fully on-device

PhotoKit reads, Vision analyses, native delete — nothing ever leaves your Mac.

✨

Keeps the genuinely best frame

Reads Apple's own quality scores to keep the sharpest, best-composed frame — not just the biggest file.

😊

Face-aware

Vision finds faces and open eyes, picking the frame where everyone looks their best.

🕓

Cross-time look-alikes

Apple's neural feature prints find the same photo saved on different days, not just time bursts.

⭐

Favorites are sacred

Favorites are never deleted; videos are skipped by default. Safe by default.

↩️

Always recoverable

Deletions go to Recently Deleted — recoverable for 30 days, synced across your devices.

Get started

No Xcode — one command builds a double-clickable app.

1 · Clone

git clone https://github.com/CVERInc/snapsift
cd snapsift/app

2 · Build the app

./scripts/build-app.sh        # → ~/Desktop/snapsift.app

3 · Scan, review, delete

Double-click snapsift.app (first time: right-click → Open). It asks for Photos access on first scan. Scan → review each cluster → delete the extras.
